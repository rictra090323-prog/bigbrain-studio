# Idea lab

Start with the decision and the constraints that would make it consequential. Generate up to three approaches that change the governing assumption, mechanism or workflow. Give each an initial step, a failure condition and the least expensive way to learn whether it works.

Critique the strongest candidate using the same criteria as the others. Separate evidence in the supplied material from speculation. Favor the experiment that would change the decision, with a cost and a stopping rule. Cite relevant local sources when they exist.

The divergence and critique structure draws on [i-have-adhd](https://github.com/hackersatyamrastogi/i-have-adhd).
