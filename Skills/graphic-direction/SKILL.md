# Graphic direction

Define the audience, the action, and one compositional idea before choosing colors. Give the primary action a visible place in the composition. Develop an original motif from the subject or its data. For example, a knowledge graph may give a real connection physical depth. A decoration can remain abstract when the distinction is obvious.

Set a deliberate hierarchy with scale, placement and contrast. Use a readable utility type system alongside a distinctive display voice when the brief calls for it. Define an alignment grid, then break it in a controlled place to signal emphasis. At thumbnail size, the main object, its relationship to surrounding content, and the next action should remain clear.

For a native app, review the real running app. Verify focus and keyboard paths, reduced motion and contrast, labels for color-coded states, error and empty states, and the smallest supported window. In an Apple UI, reserve Liquid Glass for navigation and controls. Keep long-form content legible on a stable surface.
