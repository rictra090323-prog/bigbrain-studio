# Design references

- Composition and poster craft. Define the visual thesis before arranging the elements. Build rhythm through scale and repetition, use negative space deliberately, and refine alignment and typography before adding detail. [Anthropic canvas design](https://github.com/anthropics/skills/tree/main/skills/canvas-design).
- Product art direction. Decide the visual character from the brief and carry it across the system, down to type hierarchy, spatial rhythm, color, and motion. [Anthropic frontend design](https://github.com/anthropics/skills/tree/main/skills/frontend-design).
- Editorial and identity studies. Pick specific references for editorial grid, type or identity and inspect the source in isolation before adopting a rule. [X3 All-American Design Skills](https://github.com/x3allamerican/design-skills).
- Critique an actual render. Describe the friction, tie it to a user task, and repair hierarchy, spacing or density before restyling. Use the project as a vocabulary for critique. [Impeccable](https://github.com/pbakaus/impeccable).
- For SwiftUI, run a stack-specific usability pass covering focus, interaction, spacing and accessibility. [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill).
- For macOS glass, preserve a predictable reading surface and use the native material for navigation and control layers. [Apple Liquid Glass](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views).
