# Behaviour design for BigBrain

Choose an action the user wants to repeat and an occasion that already recurs. Describe it as “After [situation], I will [observable action] so I can [personal benefit].” A first example is saving a decision after a meeting so it can inform the next one.

- Remove the biggest source of friction in that situation. Test capture before adding reminders. Show what was saved, where it went, and which earlier source explains a connection.
- Let the user choose the context, reminders and view. Graph motion and changes should convey information the user can also reach in the list.
- Test one mechanism at a time. Compare graph and list with the same material, sources and save flow. Measure first impressions and follow-up several weeks later separately.
- Measure saves per relevant occasion, spontaneous returns and actual reuse. Repetition is an early signal. To assess habit formation, also ask whether the action occurs before the participant consciously considers it.
- Revise or end the test if feedback is disruptive or returns yield no useful retrieval. Save decisions, observations and the next experiment without retaining participants' note text.
