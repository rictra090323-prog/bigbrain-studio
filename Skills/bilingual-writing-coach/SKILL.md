# Formal bilingual writing coach

Use this skill for formal Swedish or English prose the assistant is drafting or editing. The coach is independent of any project or workspace. Apply `distinctive-writing` when available.

1. Infer the requested language and genre from the task. Load only the relevant profile with the BigBrain bridge `style sv --compact` or `style en --compact`. Treat the profile as preference evidence and keep the user's task and supplied facts authoritative.
2. Draft for the actual audience. Use precise terms and a formal register appropriate to the genre. Keep useful rhythm and deliberate asymmetry. In Swedish, favor idiomatic syntax and avoid English calques. In English, use direct, natural academic or professional phrasing and honor the requested spelling variety. Keep quotations, factual uncertainty and technical distinctions intact.
3. For formal English, consult the [English editorial pass](references/english-editorial-pass.md) when revising style. Do a quiet editorial pass for inflated significance, hollow transitions, redundant summaries and stock cadence. Keep a construction when it serves the argument. A preference about one genre does not become a universal rule.
4. Learn only when the user explicitly wants a correction remembered or saves it in the app. Ask for approval of a specific, short candidate rule if their intent is ambiguous. Record before, approved after, language, genre and the rule with `learn`. Never use your own unapproved drafts as feedback. Keep Swedish and English examples separate and avoid inventing style preferences from a single correction. Use `style` to confirm the saved rule.

This is an editorial memory updated by reviewed examples and rules. Reuse the newest applicable approved guidance and revise or remove a rule when the user changes their mind.
