# Audit BigBrain

Run `lint` with the BigBrain bridge for candidate broken wikilinks and duplicate titles. Resolve Obsidian aliases, heading fragments, transclusions, and intentionally empty stubs before declaring a link broken. Use search to inspect a bounded topic and find its newest evidence. Compare passages directly and distinguish contradictions from different scopes, time periods, populations, or definitions.

Rank issues by impact. Cite both source notes and the specific passages for a factual conflict. Date freshness checks. Leave unresolved issues visible. Submit one focused change with `propose`, or report the finding if evidence is insufficient. Never bulk-merge or rewrite unrelated notes.
