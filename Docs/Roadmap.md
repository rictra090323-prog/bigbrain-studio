# BigBrain Studio roadmap

BigBrain Studio collects study notes, drafts and information worth keeping. The library stays on the Mac. Atlas shows how documents connect, and Library searches their content.

## Studio 2.3

- Atlas searches the library and previews matching documents. Its inspector shows a selection from the graph until you open items, then lists recently opened notes for the current library.
- Capture and Edit open the same document editor. Use the formatting and list controls, inspect Markdown, search the current note with ⌘F, and save with ⌘S. Link suggestions and version history are available for saved notes.
- Export the current text, including unsaved changes, to PDF, Word or Markdown. PDF and Word reproduce the supported styles. Markdown preserves the source text.
- Save Mac captures to the library or inbox. The iPhone pilot saves text locally and can transcribe recordings on supported iOS 26 devices. Review the text, then transfer the file by AirDrop and import it on the Mac.
- Writing Coach is in the sidebar. The Studio preview groups Radar and Skills under Tools.

## Next tests

1. Observe someone writing a longer study note, switching to full screen, finding a passage, and exporting to Word and PDF. Record the formatting controls they miss, especially for highlighting, tables, images and layout.
2. Verify the iPhone workflow on a physical device, including Swedish and English speech, saving, AirDrop and repeated imports.
3. Test source-backed links using real study notes with permission. Measure whether the system finds the right source and whether the writer chooses to keep the link.
4. Test cross-device transfer with acknowledgement. Keep the phone's copy until the Mac confirms it saved the note.
