# Features and next steps

| Workflow | What you can try |
| --- | --- |
| Atlas | Search the library, rotate the graph and preview a recently opened note. |
| Write | Format headings, quotes, lists and checklists. Undo changes, redo them and find text with ⌘F. |
| Export | Save the current draft as PDF, Word or Markdown. |
| Find connections | Start with a paragraph or selection, read the source excerpt and decide whether to keep the link in Atlas. |
| Capture | Press ⌘N to use the full editor on Mac, or save a text or voice note with the iPhone pilot. |
| Import | Open a Markdown library, Word document or iPhone capture file. |
| Model and skills | Choose a model provider and review skills drafted from recurring research workflows. |
