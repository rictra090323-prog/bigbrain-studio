# Funktioner och nästa steg

| Flöde | Går att prova |
| --- | --- |
| Atlas | Sök direkt till Biblioteket, rotera nätet och öppna en förhandsvisning från listan med de senaste anteckningarna. |
| Skriva | Redigera i arbetsytan eller helskärm. Formatera rubriker, fetstil och kursiv, citat, punktlistor, numrerade listor och checklistor. Ångra, gör om och sök med ⌘F. |
| Exportera | Spara den öppna texten som PDF, Word eller Markdown. |
| Hitta samband | Utgå från ett stycke eller en markering, läs ett källutdrag och välj om länken ska sparas i Atlas. |
| Fånga | Skriv med ⌘N på Mac eller spara en text- eller röstanteckning i iPhone-piloten. |
| Importera | Läs in ett Markdown-bibliotek, ett Word-dokument eller en fångstfil från iPhone. |
| Verktyg | Öppna Radar, Skrivcoach och Skills vid behov. |
